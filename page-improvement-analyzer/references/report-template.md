## テンプレート使用ルール

- 各改善項目はチェックボックス `- [ ]` 形式にして、対応状況を追跡可能にする
- 問題がないカテゴリの優先度セクションは省略してよい（例: Criticalが無ければ記載しない）
- カテゴリ自体に問題が無い場合は「問題なし」と1行で記載
- 計測値テーブルは Performance と Network のみ必須
- 末尾の「改善アクション優先順位」にはCritical項目を中心に最大10件を列挙する
- 具体的な数値（ms, KB, 個数等）を必ず含め、曖昧な記述を避ける
